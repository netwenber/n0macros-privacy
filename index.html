n0macros: Privacy Policy

Last updated: August 23, 2026

n0macros is a free browser extension that helps you type faster in any input field: insert saved text snippets and templates, correct text typed in the wrong keyboard layout, fix wording with on-device AI, and auto-fill forms with saved or generated placeholder data.

This policy explains what data the extension handles, where it is stored, and what (if anything) leaves your device.

1. Data the extension stores

n0macros stores the following locally, in your browser (chrome.storage.local):

  • Text snippets and folders you create: the macros/templates themselves, their names, and how you've organized them.
  • Settings: your preferences (appearance, hotkeys, language, feature toggles).
  • Form-fill profiles: if you use the form-filling feature, the extension saves the field labels, CSS selectors, and the values you typed when recording a profile, so it can fill the same form again later. Password fields are never scanned, recorded, or filled.

None of this data leaves your device unless you explicitly turn on Google Drive backup (see section 2).

2. Google Drive backup (optional)

If you choose to sign in and enable backup, the extension writes the data described in section 1 to a hidden, app-specific folder in your own Google Drive, using the restricted drive.appdata scope. This scope:

  • Only gives the extension access to a private folder it creates for itself.
  • Does not give the extension access to any other file in your Drive.
  • Cannot be seen or opened by you (or anyone else) directly in the regular Google Drive interface; it exists solely as a backup channel for this extension.

Your Google sign-in token is held only in memory for the current session and is never stored permanently or sent anywhere other than Google's own servers to perform the backup/restore action you requested.

If you never enable this feature, no data ever leaves your browser.

3. AI text correction (on-device, experimental)

The text-proofreading feature uses Chrome's built-in, on-device AI model (Gemini Nano, via the Chrome Prompt API). When you use it:

  • The text you select is processed locally on your own computer.
  • It is never sent anywhere by n0macros itself: the extension makes no network request when using this feature. (You can verify this yourself: the extension's code contains no fetch or network calls in this module.)

How Chrome's built-in AI model itself operates internally is part of the browser platform, not this extension. We can only speak to what our own code does.

4. Data we generate, but do not collect

The form-filling feature can optionally insert synthetic placeholder data (e.g. {{faker.name}}, {{faker.email}}, {{faker.iban}}) for testing purposes. This data is:

  • Randomly generated on your device: it does not belong to, or describe, any real person.
  • Never stored beyond the moment it's inserted into a field.
  • Not sent anywhere.

5. What we don't do

  • We do not sell your data.
  • We do not share your data with third parties.
  • We do not use your data for advertising.
  • We do not track your browsing activity.
  • The extension does not include any analytics, telemetry, or tracking code of any kind.

6. Children's privacy

n0macros is not directed at children under 13, and we do not knowingly collect data from children under 13.

7. Changes to this policy

If this policy changes (for example, if a future version adds a new feature that touches user data), this page will be updated, and the "Last updated" date above will reflect the change.
